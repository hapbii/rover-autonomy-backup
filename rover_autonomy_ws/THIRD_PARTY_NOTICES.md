# Third-party components

The palm detector model is `palm_detection_mediapipe_2023feb.onnx` from
[OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/palm_detection_mediapipe).
That directory and model are Apache-2.0 licensed. The full license is bundled in
`src/rover_autonomy/models/PALM_LICENSE.txt`; the exact repository commit and Git-LFS
SHA-256 are recorded in `palm_manifest.json`.

`vision/hands.py` is a separate, modified implementation of that model's documented
decoding scheme, with generated anchors, corrected xywh NMS and bounded targets.

OpenCV, NumPy, PyYAML, pyserial, pytest, psutil and Ruff retain their upstream licenses.
The sibling `yolo_dataset` has unverified provenance and is not this project's supplied training data.
An early experiment mistakenly used it; all derived weights/crops/reports are archived under
`experiments/unverified_workspace_dataset`, excluded from default operation and distribution bundles.
Default sign fixtures are synthetic graphics generated by `scripts/make_synthetic_assets.py`.
No real-camera sign recognition accuracy is currently claimed.
