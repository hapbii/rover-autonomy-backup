# 배선 작업 목록과 최종 배선안

**상태: 코드 Pi 배포·빌드 완료. 실물 배선 확인과 새 펌웨어 업로드는 아직 안 함. Uno USB 장치가 보이지 않으며 실제 모터 출력은 실행하지 않았음.**
마지막으로 실제 동작한 것은 TB6612 1개/모터 2개, STBY=D10의 EM2 PWM 테스트입니다.
**최신 배선은 사용자 요청대로 STBY=D10을 유지합니다.** 앞서 D13으로 바꾸자고 한 것은 D10을 오른쪽 뒤 엔코더 A상에 배정했기 때문입니다. 현재 카메라 구성의 여유 핀 A2로 그 엔코더 입력을 옮겨 D10을 비웠습니다. **D10에는 STBY만 연결하고 엔코더 신호를 연결하지 않습니다.** 새 펌웨어는 아직 업로드하지 않았습니다.

## 1. 드라이버 1=오른쪽, 드라이버 2=왼쪽

각 드라이버 안에서 두 모터가 같은 PWM과 방향을 받도록 **입력**만 묶습니다. 서로 다른 쪽의 PWM/방향은 분리합니다.

| 드라이버 입력 | 1번: 오른쪽 | 2번: 왼쪽 |
|---|---|---|
| PWMA와 PWMB | 둘 다 D3 | 둘 다 D5 |
| AIN1과 BIN1 | 둘 다 D9 | 둘 다 D11 |
| AIN2와 BIN2 | 둘 다 D8 | 둘 다 D12 |
| STBY | D10 | D10 |

| 드라이버 | 출력 | 모터 |
|---|---|---|
| 1 | AO1/AO2 | 오른쪽 앞 구동용 두 선 |
| 1 | BO1/BO2 | 오른쪽 뒤 구동용 두 선 |
| 2 | AO1/AO2 | 왼쪽 앞 구동용 두 선 |
| 2 | BO1/BO2 | 왼쪽 뒤 구동용 두 선 |

AO/BO 출력은 드라이버끼리 연결하지 않습니다. 모터 한 개를 한 채널에 연결합니다. 차량 설치 방향에 맞춰 모터 구동용 두 선을 바꿔 전진 방향을 맞출 수 있습니다.

양쪽 모두 전진할 때 오른쪽 PWM이 크면 좌회전, 왼쪽 PWM이 크면 우회전합니다. 제자리 회전은 한쪽 전진/다른 쪽 후진이며 위처럼 방향 제어도 분리되어 있어야 합니다. PWM은 측정 속도가 아니므로 엔코더로 보정합니다.

## 2. 엔코더 네 개

| 위치 | A상 -> Uno | B상 -> Uno |
|---|---|---|
| 왼쪽 앞 (LF) | D2 | D4 |
| 오른쪽 앞 (RF) | D6 | D7 |
| 왼쪽 뒤 (LR) | A3 | A4 |
| 오른쪽 뒤 (RR) | A2 | A5 |

각 엔코더 VCC는 5V, GND는 공통 GND입니다. 실제 FIT0450 기판의 A/B/VCC/GND 순서가 아직 확인되지 않았으므로 색상만으로 연결하지 않습니다. 모터 구동용 빨강/검정 두 선과 엔코더 전원/신호는 구분합니다.

펌웨어는 PCINT로 A상 상승 에지(x1)를 세며 B상으로 방향을 구분합니다. 출력축 한 바퀴의 실제 계수와 네 엔코더 부호를 확인해야 합니다.

## 3. 현재 개발 코드: 카메라 라인 추종 + 초음파

사용자가 카메라로 라인을 따라가도록 요청했으므로 IR 입력 대신 다음 핀을 사용합니다.

| 연결 대상 | Uno |
|---|---|
| 초음파 TRIG | A0 |
| 초음파 ECHO | A1 |
| A2 | 오른쪽 뒤 엔코더 A상 (위 표) |
| D13 | 미사용 |
| IR 센서 출력 3개 | 이 프로필에서는 연결하지 않음 |

TRIG/ECHO형 초음파(예: HC-SR04)를 가정한 코드입니다. 실제 초음파 모델은 아직 확인되지 않았습니다. VCC/단자 규격이 다른 제품이면 먼저 사양에 맞춰 변경해야 합니다. 일반 5V HC-SR04라면 VCC=Uno 5V, GND=공통 GND이며 ECHO는 Pi GPIO가 아닌 Uno에 연결합니다.

**A0/A1을 IR 출력과 초음파에 동시에 연결하면 안 됩니다.**

## 4. 이전에 논의한 IR 3개 사용 배선안 (별도 프로필)

이전 논의에서는 SEN200621의 왼쪽 끝/가운데/오른쪽 끝 출력만 A0/A1/A2에 연결하는 안이었습니다. 왼쪽부터 1~5 순서라면 1/3/5입니다. **이것은 현재 펌웨어의 배선 지시가 아닙니다.** 현재 A0/A1은 초음파, A2는 오른쪽 뒤 엔코더 입력이므로 IR 출력을 함께 연결하면 안 됩니다. 실제 커넥터 좌우/핀 순서와 전압도 확인해야 합니다.

IR 3개로 전환한다면 초음파를 제외하고 오른쪽 뒤 엔코더 A상도 A2에서 다른 핀(예: D13)으로 재배정하는 별도 설계/펌웨어가 필요합니다. 드라이버 7 + 엔코더 8 + IR 3 = 18핀을 모두 사용하여 초음파 TRIG/ECHO를 동시에 직접 연결할 여유가 없습니다. 현재 `rover_camera.ino`는 IR 프로필을 실행하지 않습니다. IR과 초음파를 모두 쓰려면 핀/보드 확장이나 재설계가 필요합니다.

## 5. 전원과 통신

| 연결 대상 | 위치 |
|---|---|
| Raspberry Pi | USB 케이블로 Uno USB 단자 연결 |
| Uno 5V | 드라이버 1/2 VCC, 엔코더 VCC, 해당 5V 센서 VCC |
| 외부 6V 전원 + | 드라이버 1/2 VM |
| 외부 전원 - | 드라이버 GND 및 Uno GND와 공통 |
| 모든 센서 GND | 위 공통 GND |
| Uno D0/D1 | USB 시리얼용 예약 |

외부 6V를 Uno 5V 핀에 연결하지 않습니다. 모터 전류는 VM 전원에서 공급합니다. 드라이버가 모터의 구속 전류를 계속 감당할 수 있는 조합은 아니므로 초기 시험은 바퀴를 띄운 낮은 출력으로 진행합니다.

카메라+초음파 구성은 제어 7 + 엔코더 8 + 초음파 2 = 17핀, D13 한 개가 남습니다. Uno D0/D1은 다른 장치에 연결하지 않습니다.

## 6. 실물 복귀 후 해야 할 일

- 실제 엔코더 커넥터의 A/B/VCC/GND 확인.
- 실제 초음파 모델/핀/전압 확인.
- 기존 펌웨어 백업 유지. 이전 백업은 `~/robot_ws/firmware/backups/uno_before_two_motor_20261111_113701/`에 있었음.
- STBY는 D10에 유지. RA1 새 펌웨어와 핀 구성을 확인한 뒤 센서 배선 연결. 오른쪽 뒤 엔코더 A상은 A2이며 D10에는 연결하지 않음.
- 손으로 각 바퀴를 돌려 LF/RF/LR/RR 계수/부호 확인.
- 바퀴 반지름, 좌우 바퀴 중심 간격, x1 counts/rev 실측.
- 저출력 정방향/역방향, 초음파 거리, 카메라 시야 확인.
- 실제 라인/신호/화살표/손 영상으로 인식 및 정지 조건 조정.
- Pi의 ROS 통신, 프레임 속도, 장시간 메모리와 실제 주행 검증.

이번 로컬 작업에서는 위 실물 작업을 수행하지 않았습니다. 이 파일은 나중에 배선을 다시 물어볼 때 기준으로 사용합니다.
