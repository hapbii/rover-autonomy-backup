# 격리 보존한 참고 자료

상위 작업 폴더 삭제에 대비해 로버와 관련된 기존 자료를 보존합니다.

- `unverified_original_yolo_dataset`: 출처/이번 프로젝트 적합성이 확인되지 않은 원본 데이터. 사용자가 이번 프로젝트용으로 제공한 라벨이라고 주장하지 않습니다. 현재 표지판의 실제 인식률 근거가 아닙니다.
- `picar_validation_history`: 기존 PiCar 참고 코드·수정/검증 결과·실행 환경. 현재 ROS 2 패키지가 자동으로 사용하는 코드가 아닙니다.
- `PiCar_B_MarsRover_vendor_20260407.zip`: 기존 폴더에 있던 PiCar 참고 ZIP 그대로 보존.
- `picar_progress.pdf`, `build_picar_report.py`: 기존 PiCar 진행 기록과 생성 코드.

이 자료의 백업은 현재 차량에서 동작·정확도·하드웨어 호환성을 검증했다는 뜻이 아닙니다. 원래 파일 이름/경로는 루트 `BACKUP_MANIFEST.json`의 restore_path로 확인합니다. 원본 라이선스는 각 자료 안에 보존되어 있습니다.
